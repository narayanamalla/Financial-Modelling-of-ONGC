# 📊 ONGC Financial Modeling & Valuation

A comprehensive financial analysis and valuation framework for **Oil and Natural Gas Corporation (ONGC)**, providing deep insights into the company's financial performance, intrinsic value, and investment potential through advanced financial modeling techniques.

## 📈 Project Overview

This repository contains a sophisticated financial model that transforms raw financial data into actionable investment intelligence. The model follows professional valuation methodologies used by equity research analysts and investment professionals to assess ONGC's financial health and fair value.

## 🔍 Key Analysis Modules

### 📋 Financial Statement Analysis
- **Profit & Loss Statements** - Historical performance tracking
- **Balance Sheet Analysis** - Asset composition and capital structure
- **Cash Flow Analysis** - Operating, investing, and financing activities
- **Quarterly Performance** - Short-term trend analysis

### 📊 Ratio & Trend Analysis
- **Profitability Ratios** - OPM, Net Margins, ROE, ROIC
- **Liquidity & Efficiency** - Working capital, turnover ratios
- **Solvency Metrics** - Debt ratios, interest coverage
- **Common Size Statements** - Percentage-based financial analysis

### 🔮 Forecasting & Projections
- **Sales Forecasting** - Historical growth trend analysis
- **EBITDA Projections** - Operating performance outlook
- **EPS Forecasting** - Earnings per share growth modeling
- **Statistical Forecasting** - Using Excel FORECAST functions

### 💰 Valuation Models
- **DCF Valuation** - Free Cash Flow to Firm (FCFF) methodology
- **WACC Calculation** - Weighted Average Cost of Capital
- **Relative Valuation** - Comparable company analysis (Comps)
- **Football Field Analysis** - Multi-method valuation summary

### ⚠️ Risk Assessment
- **Beta Analysis** - Stock volatility and market risk
- **Value at Risk (VaR)** - Statistical risk measurement
- **Sensitivity Analysis** - Scenario-based valuation impacts

## 🛠️ Technical Features

- **Excel-Based Framework** - Fully formula-driven with dynamic linkages
- **Data Integration** - Compatible with Screener.in data exports
- **Automated Calculations** - Real-time ratio and metric computations
- **Scenario Analysis** - Best case/worst case projections
- **Visual Dashboards** - Football field charts and sensitivity tables

## 🎯 Use Cases
